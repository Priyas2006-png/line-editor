## Reflection

Through these five HackerRank problems, I learned how algorithmic efficiency affects the performance and quality of a program. The problems covered matrix traversal, dynamic arrays, string processing, element-wise comparison, and frequency mapping. I learned that choosing an appropriate data structure can reduce unnecessary computation. For example, the Sparse Arrays problem can be solved efficiently using a hash map instead of repeatedly comparing every query with every string. The Dynamic Array problem also demonstrated how vectors and bitwise XOR can be used to organize data efficiently.

I also improved my understanding of time and space complexity. Problems such as Time Conversion and Compare the Triplets require only a constant amount of work, while Diagonal Difference can be solved with a single traversal of the matrix. This helped me understand why avoiding unnecessary nested loops is important when working with large inputs. Maintaining a separate GitHub repository also taught me the importance of organizing source code, documenting solutions, and maintaining a professional coding portfolio. Overall, this activity strengthened my problem-solving skills and gave me practical experience solving programming challenges on an industry-recognized platform.
